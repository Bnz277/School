快速开始

欢迎使用 NYLG 智能网络爬虫工具！本工具提供了简单易用的网络数据采集功能。

1
选择爬虫类型
根据需求选择百度、B站、CSDN或自定义网页
2
输入参数
填写关键词或URL等必要参数
3
开始爬取
点击开始按钮，等待数据采集完成
4
导出数据
选择合适的格式导出采集结果

功能介绍

百度搜索爬虫

快速获取百度搜索结果，包括标题、链接、摘要等信息。

  • 支持关键词搜索
  • 可设置最大结果数
  • 自动去重处理
B站视频爬虫

采集B站视频信息，包括标题、作者、播放量、发布时间等。

  • 视频详细信息
  • 作者和播放数据
  • 发布时间记录
CSDN技术爬虫

专门针对CSDN技术文章的数据采集工具。

  • 技术文章内容
  • 作者和阅读量
  • 发布和更新时间
自定义网页爬虫

支持任意网页的内容提取，智能识别主要内容。

  • 智能内容识别
  • 自动编码检测
  • 内容清理优化

使用方法

1. 搜索类爬虫使用

参数说明：
• 关键词：要搜索的内容
• 最大结果数：限制返回的结果数量（建议不超过20，最大100）

2. 网页爬虫使用

参数说明：
• 目标URL：要爬取的网页地址
• 支持HTTP和HTTPS协议
• 自动处理重定向和编码问题

3. 注意事项

重要提醒：
  • 请遵守目标网站的robots.txt协议
  • 合理控制爬取频率，避免对服务器造成压力
  • 仅用于学习和研究目的
  • 尊重网站的版权和隐私政策

数据导出

JSON格式

结构化数据格式，适合程序处理

推荐用于数据分析和二次开发
CSV格式

表格数据格式，可用Excel打开

推荐用于数据统计和报表制作
TXT格式

纯文本格式，便于阅读和编辑

推荐用于内容查看和简单处理

常见问题

可能的原因包括：网络连接问题、目标网站反爬虫机制、URL格式错误等。请检查网络连接和URL格式，如果问题持续存在，请稍后重试。

目前支持百度搜索、Bilibili、CSDN以及大部分常规网页。对于有严格反爬虫机制的网站，可能无法正常访问。

我们使用智能解析算法提取内容，准确率在95%以上。但由于网页结构的复杂性，建议在使用前先进行小规模测试。

API接口

爬取接口

POST /api/crawl

请求参数：
{ "spider_type": "baidu|bilibili|csdn|url",
"keyword": "搜索关键词", // 搜索类爬虫必填
"url": "目标网址", // URL爬虫必填
"max_results": 10 // 最大结果数，可选
}

任务状态查询

GET /api/task/{task_id}

返回数据：
{ "success": true,
"status": "completed",
"results": [...],
"message": "任务完成" }
