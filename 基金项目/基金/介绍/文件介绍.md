# 项目文件介绍

## 1. 根目录文件

- `README.md`: 项目的简要介绍、安装和使用说明。
- `requirements.txt`: 项目所需的所有 Python 依赖库及其版本，用于 `pip install -r` 安装。
- `app.py`: (如果存在) 项目的 Flask/Django 等 Web 框架的入口文件，负责启动 Web 服务。
- `crawler_main.py`: 爬虫项目的核心启动文件，负责调度和运行爬虫任务。
- `.gitignore`: Git 版本控制忽略文件，定义了不需要提交到版本库的文件和目录。
- `.venv/` 或 `.venv1/`: Python 虚拟环境目录，包含了项目独立的 Python 解释器和依赖库。

## 2. `src/` 目录

`src` 目录是项目的核心代码存放位置，包含了所有功能模块。

### 2.1. `src/api/`

该目录存放与外部系统交互的 API 接口定义和实现，例如：

- `__init__.py`: Python 包的标识文件。
- `bilibili.py`: 处理与 Bilibili 相关的 API 请求和数据交互。
- `crawl.py`: 提供用于触发和管理爬虫任务的 API 接口。
- `stats.py`: 提供数据统计和分析相关的 API 接口。

### 2.2. `src/core/`

该目录包含项目的核心逻辑和状态管理，例如：

- `__init__.py`: Python 包的标识文件。
- `state.py`: 定义和管理项目的全局状态或配置。

### 2.3. `src/services/`

该目录包含业务逻辑服务层，封装了具体的业务操作，供 API 或其他模块调用，例如：

- `__init__.py`: Python 包的标识文件。
- `bilibili_auth.py`: 处理 Bilibili 认证相关的业务逻辑。
- `bilibili_download.py`: 处理 Bilibili 视频下载相关的业务逻辑。
- `crawler_service.py`: 封装了爬虫服务的具体实现，如任务调度、数据存储等。

### 2.4. `src/spiders/`

该目录是爬虫项目的核心，包含了各种网站的爬虫实现，例如：

- `__init__.py`: Python 包的标识文件。
- `baidu_spider.py`: 百度搜索引擎的爬虫实现。
- `bilibili_spider.py`: Bilibili 网站的爬虫实现。
- `csdn_spider.py`: CSDN 网站的爬虫实现。
- `url_extractor.py`: 通用的 URL 提取器，用于从网页中提取链接。

### 2.5. `src/utils/`

该目录存放项目中的通用工具函数和辅助模块，例如：

- `__init__.py`: Python 包的标识文件。
- 其他可能存在的工具文件，如日期处理、字符串处理、网络请求辅助函数等。

### 2.6. `src/frontend/`

该目录存放前端相关的代码和资源，例如：

- `static/`: 静态文件，如 CSS、JavaScript、图片等。
- `templates/`: HTML 模板文件。
- `vue/`: 如果项目使用 Vue.js 等前端框架，则存放前端项目的源代码。

### 2.7. `src/crawler_results/`

该目录用于存放爬虫运行后产生的数据结果，例如 JSON 文件、CSV 文件等。

### 2.8. `src/downloads/`

该目录用于存放爬虫下载的文件，例如图片、视频或其他二进制文件。

### 2.9. `src/介绍/`

该目录专门用于存放项目的说明文档，包括：

- `README.md`: 项目的整体介绍。
- `文件介绍.md`: 本文档，详细介绍项目的文件结构和功能。
- `宝塔面板部署.md`: 部署到宝塔面板的详细指南。
- `自定义内容.md`: 说明如何自定义项目内容。

## 3. 其他文件和目录

- `.idea/`: PyCharm 等 IDE 的项目配置文件，通常不需要手动修改。
- `测试/`: 项目的测试文件和测试用例，用于验证代码的正确性。**此目录下的文件不应被修改。**
