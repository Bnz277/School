# Python 爬虫项目说明文档

## 1. 项目概述

本项目是一个基于 Python 的爬虫项目，旨在从特定网站抓取数据。它包含多个爬虫模块，每个模块针对不同的网站或数据类型进行优化。项目结构清晰，易于扩展和维护。

## 2. 环境搭建

### 2.1. Python 环境

本项目推荐使用 Python 3.9.7 版本。编译工具为 pycharm


### 2.2. 安装依赖

通过 `requirements.txt` 文件安装所有必要的 Python 库。

```bash
pip install -r requirements.txt
```

### 2.3. 其他配置

根据项目需求，可能需要配置数据库连接、API 密钥等。具体配置请参考 `src/config.py` (如果存在) 或相关模块的说明。

## 3. 项目结构
src/
├── api/                # API 接口定义
├── core/               # 核心逻辑和状态管理
├── crawler_results/    # 爬虫结果存放目录
├── downloads/          # 下载文件存放目录
├── frontend/           # 前端相关文件
├── services/           # 服务层，处理业务逻辑
├── spiders/            # 爬虫模块，包含各种爬虫实现
├── utils/              # 工具函数
└── 介绍/               # 项目说明文档
└── README.md       # 本文档

## 4. 运行项目

项目的主入口通常是 `crawler_main.py` 或 `run.py`。根据您的需求，可以通过命令行参数或修改代码来指定爬取目标。

```bash
# 一键运行项目
python run.py
```

## 5. 常见问题与解决方案

- **依赖安装失败**: 检查 `requirements.txt` 文件是否完整，并确保网络连接正常。
- **爬取数据为空**: 检查目标网站结构是否发生变化，或爬虫规则是否需要更新。
- **IP 被封禁**: 考虑使用代理 IP 池或调整爬取频率。
